#### *ENTERPRISE NETWORK PORTFOLIO*





##### \# Project Overview



&#x20;  The REC TECH COMPANY Network Topology project focuses on the design and documentation of a computer network infrastructure for REC TECH COMPANY.The project illustrates how different network devices are interconnected to facilitate communication and resource sharing within the company.





##### \# Project Objectives



The objectives of this project are to:



\- Design a structured computer network topology.

\- Illustrate the interconnection of network devices.

\- Identify the functions of the devices used in the network.

\- Explain how the network infrastructure supports communication and resource sharing.

\- Examine the advantages of implementing the proposed network infrastructure.

\- Identify appropriate security measures for protecting network resources and information.

\- Provide technical documentation for future reference.

##### \# Network Topology Type: STAR TOPOLOGY



|-The network adopts a Star Topology in which the connected devices communicate through a central Core Switch.



|-The router connects to the Core Switch and serves as the network gateway.



|-The desktop computers, printer and file server are connected to the Core Switch.



##### \# Network Operation



The network allows connected devices to communicate and share resources through the Core Switch.



###### &#x20;Local Network Communication



When an employee accesses a file stored on the company's file server:



1\. The employee initiates a request from a desktop computer.

2\. The request is transmitted to the Core Switch.

3\. The switch forwards the request towards the destination device using MAC address information.

4\. The file server receives and processes the request.

5\. The requested information is transmitted back through the Core Switch to the requesting computer.



This communication normally takes place within the Local Area Network (LAN).



###### &#x20;External Network Communication



When an employee wants to access an external website:



1\. The desktop computer generates a request.

2\. The request passes through the Core Switch.

3\. The Core Switch forwards the traffic to the Router, which serves as the default gateway.

4\. The Router directs the traffic towards the external network.

5\. The response returns through the Router and Core Switch to the requesting computer.



##### \# Functions of the Main Network Devices



\- **Router**: Connects different networks and provides a gateway to external networks.

\- **Core Switch**: Serves as the central connection point for devices within the company's LAN.

\- **Desktop Computers**: Allow employees to access network resources and perform daily computing tasks.

\- **Printer**: Provides printing services to authorized network users.

\- **File Serve**r: Provides centralized file storage and sharing services.



##### \# Advantages of the Network



The REC\_TECH COMPANY network provides several benefits to the organization:



1\. **Resource Sharing**: Employees can share resources such as printers and files across the network.

2\. **Centralized Storage**: The file server provides a central location for storing and accessing company files.

3\. **Improved Communication**: Connected computers can communicate and exchange information.

4\. **Easy Network Management**: The Core Switch provides a central connection point for managing network connectivity.

5\. **Scalability**: Additional computers and network devices can be connected as the company expands, provided sufficient network capacity is available.



##### \# Network Security



***Network security*** refers to the measures taken to protect the company's network, devices and information from unauthorized access and security threats.



The following security measures are recommended for REC\_TECH COMPANY:



1\. ***Strong Passwords:*** Use strong passwords to protect computers, routers and servers.

2\. ***Firewall Protection***: Helps monitor and control incoming and outgoing network traffic.

3\. ***Antivirus Software:*** Helps detect and prevent malicious software.

4\. ***Access Control:*** Ensures that only authorized employees can access specific network resources.

5\. ***Regular Backups***: Maintains copies of important company files to support data recovery when necessary.



##### \# Conclusion



The REC\_TECH COMPANY Network Topology project presents a proposed Star Topology network designed to support communication and resource sharing within the organization.



The network uses a Core Switch as the central connection point for five desktop computers, a printer and a file server. A router provides connectivity to external networks.



The proposed design offers benefits such as centralized file storage, resource sharing, improved communication and easier network management.



By implementing appropriate security measures, REC\_TECH COMPANY can protect its network resources and information.



Overall, this project provides a foundation for a structured, manageable and expandable computer network infrastructure.
